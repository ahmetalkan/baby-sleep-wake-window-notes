# Baby Sleep Wake-Window Notes and Safe Sleep Checklist

Practical parent reference notes covering infant sleep pressure, early-month rhythm shifts, nap transitions, and safe crib setup citing AAP, NICHD, NHLBI, and MedlinePlus.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — infant wake-window planning notes: `https://ahmetalkan.github.io/baby-sleep-wake-window-notes/`
- Subpage — newborn sleep patterns and the 4-month shift: `https://ahmetalkan.github.io/baby-sleep-wake-window-notes/newborn-to-4-month-sleep.html`
- Subpage — recognizing and navigating nap transitions: `https://ahmetalkan.github.io/baby-sleep-wake-window-notes/nap-transitions-guide.html`
- Subpage — AAP and NICHD safe sleep checklist: `https://ahmetalkan.github.io/baby-sleep-wake-window-notes/safe-sleep-environment.html`

It cites public pages on [sleepschedulelab.com](https://sleepschedulelab.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
